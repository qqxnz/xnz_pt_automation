# 代理管理模块方案

## 1. 模块目标

代理管理模块负责维护系统可用代理，并供站点在需要时选择一个已启用代理。站点默认不使用代理。

业务边界：本模块只维护代理配置和测试代理连通性，不直接修改站点配置。

## 2. 页面和入口

页面路径：`/proxies`

入口：左侧导航、站点表单中的代理选择入口。

## 3. 功能方案

列表字段：

```text
代理名称
代理类型
地址
端口
启用状态
最近测试结果
操作
```

表单字段：名称、类型、Host、端口、用户名、密码、启用状态。

操作：新增、编辑、删除、启用、禁用、测试代理。

## 4. 接口和数据

接口：

```text
GET    /api/proxies
POST   /api/proxies
GET    /api/proxies/:id
PUT    /api/proxies/:id
DELETE /api/proxies/:id
POST   /api/proxies/:id/test
```

数据：

```ts
type ProxyConfig = {
  id: string
  name: string
  enabled: boolean
  type: 'HTTP' | 'HTTPS' | 'SOCKS5'
  host: string
  port: number
  username?: string
  password?: string
}
```

## 5. 状态和安全

- 代理密码加密存储，不明文回显。
- 删除已被站点使用的代理时需要阻止或提示先解绑。
- 测试日志不记录代理密码。
- 禁用已被站点使用的代理时需要提示影响范围；站点后续连通性检测会失败并提示代理已禁用。

## 9. 验收标准

- 可新增、编辑、删除代理。
- 密码不明文回显。
- 被站点引用的代理不会被误删。
- 可测试代理并展示结果。
- 站点只能从已启用代理中选择代理；不选择时表示不使用代理。
