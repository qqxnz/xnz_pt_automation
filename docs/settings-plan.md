# 系统设置模块方案

## 1. 模块目标

系统设置模块负责修改密码、查看系统信息、查看数据库和迁移状态、配置基础参数。

业务边界：本模块不管理站点、代理、下载器等业务配置。

## 2. 页面和入口

页面路径：`/settings`

入口：左侧导航、顶部用户菜单、默认密码风险提示。

## 3. 功能方案

页面区域：

- 修改密码。
- 系统版本。
- 数据库路径。
- 最近迁移结果。
- 登录态过期时间。
- 数据保留策略摘要。

修改密码字段：旧密码、新密码、确认新密码。

校验：旧密码必填；新密码最少 8 位；两次新密码一致；新密码不能与旧密码相同。

## 4. 接口和数据

接口：

```text
PUT /api/auth/password
GET /api/settings/system-info
GET /api/settings
PUT /api/settings
```

系统信息：

```ts
type SystemInfo = {
  version: string
  databasePath: string
  schemaVersion: string
  lastMigrationAt?: string
  lastMigrationStatus?: 'SUCCESS' | 'FAILED'
}
```

## 5. 状态和安全

- 修改密码成功后建议重新登录。
- 密码不写入日志。
- 系统信息不展示密钥类环境变量。
- 数据库路径可展示但不提供下载数据库能力。
