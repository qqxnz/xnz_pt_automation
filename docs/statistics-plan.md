# 数据统计模块方案

## 1. 模块目标

数据统计模块负责展示站点上传下载趋势、分享率趋势、每日增量和种子推送统计。

业务边界：本模块只展示已采集快照和聚合数据，不负责采集任务配置。

## 2. 页面和入口

页面路径：`/statistics`

入口：左侧导航、首页概览卡片。

## 3. 功能方案

展示内容：

- 各站点上传趋势。
- 各站点下载趋势。
- 分享率趋势。
- 每日上传增量。
- 每日下载增量。
- 种子推送数量趋势。
- 自动删除数量统计。

筛选项：时间范围、站点、指标类型。

## 4. 接口和数据

接口：

```text
GET /api/stats/overview
GET /api/stats/sites
GET /api/stats/sites/:id/traffic?range=
GET /api/stats/torrents?range=
```

趋势点：

```ts
type TrafficPoint = {
  time: string
  uploaded: number
  downloaded: number
  ratio: number
  bonus?: number
}
```

## 5. 状态和安全

- 无快照数据时展示空状态和同步流量入口。
- 图表接口失败时展示重试入口。
- 大数值统一格式化为 GB、TB。
- 不展示敏感下载链接。
