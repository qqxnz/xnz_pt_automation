# 设计规范

## 1. 适用范围

本规范用于 PT 自动化系统的前端页面设计和设计稿产出，覆盖登录页、Dashboard、站点管理、免费种子、下载器管理、代理管理、定时任务和系统设置等页面。

## 2. 技术和组件基准

- 前端技术栈：`Vue 3 + Vite + TypeScript + Varlet UI`
- 页面需要兼顾桌面、平板和手机访问
- 优先使用 Varlet UI 组件，不额外引入复杂设计系统
- 页面结构以管理后台的清晰度和可操作性为优先

## 3. 视觉基准

```text
主色             #3f7cff
成功             #10b981
警告             #f59e0b
错误             #ef4444
页面背景         #f6f8fb
卡片背景         #ffffff
主文本           #111827
次级文本         #6b7280
边框             #e5e7eb
```

状态颜色：

```text
ONLINE       绿色
OFFLINE      红色
AUTH_FAILED  橙色
UNKNOWN      灰色
```

## 4. 响应式规则

```text
mobile   < 768px
tablet   768px - 1199px
desktop  >= 1200px
```

- 桌面端优先使用侧边栏、统计卡片和表格
- 平板端保留核心导航，减少表格字段
- 移动端优先使用顶部栏、卡片列表和底部/弹层操作

## 5. 设计稿产出规则

- 后续新增或调整设计稿时，仅输出 `.svg` 文件
- 不再额外生成 PNG、JPG 或其他扁平化预览文件
- SVG 文件直接放在 `designs/` 目录下
- 文件名使用页面或模块英文名，例如 `login.svg`、`dashboard.svg`、`sites.svg`
- 如果设计稿包含多个状态，可以使用 `模块-状态.svg`，例如 `sites-empty.svg`、`sites-auth-failed.svg`

已有的 `.svg.png` 文件属于历史产物，不作为后续设计稿交付格式。

## 6. 设计稿内容要求

- 标明页面主标题和关键操作入口
- 展示主要状态和异常状态
- 包含桌面端布局；涉及核心操作的页面需要补充移动端布局
- 敏感信息默认脱敏，例如 Cookie、密钥、密码和下载链接
- 按钮数量保持克制，优先突出主操作
